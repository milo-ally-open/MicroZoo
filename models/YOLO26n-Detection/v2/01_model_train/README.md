# 01 — 模型与数据准备

v2 不训练、不微调。原始 `yolo26n.pt` 已放在 `checkpoints/` 作为来源记录。准备数据脚本把现有 COCO val32 固定拆成 24 张 PTQ 校准图和 8 张留出图。校准图不需要标签；留出图和标签留给后续 03 阶段验证。

先按 v2 README 准备 v1 权重和 `coco-val-32` 数据，再运行：

```bash
python3 01-prepare-calibration.py
```

脚本固定随机种子 `20261122`，只准备图片与标签，不下载数据，也不负责复制模型。重新运行会得到同一拆分。图片目录、checkpoint 和生成的数据文件均为本地数据，不提交到 Git。
