# OWLv2 analysis image

`coco_000000039769.jpg` is a local copy of COCO 2017 validation image `000000039769.jpg`. It is used only for the initial open-vocabulary inference smoke check. The model script reads this file from disk and does not download images.

Original image URL: https://images.cocodataset.org/val2017/000000039769.jpg

This single image is a smoke-test input, not a task-accuracy validation set.
